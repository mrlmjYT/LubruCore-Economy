# LubruCore-Economy

This is LubruCore-Economy a custom Economy Plugin


##  Features

* UI
* Balance
* bank
* Pay Command

## Commands & Usage

Players can use the following commands in-game. 


| `/economy` | Opens the economy Menu|
| `/setrank` | Set the rank of a player|
| `/balance` | Let u see ur Balance |
| `/setbalance` | Set balance of a player|
| `/addmoney` | Adds Money to a Player |


##  Installation

To install this plugin on your Minecraft server:

1. Download the latest `.jar` file from the Release page.
2. Navigate to your server's root directory and open the `plugins/` folder.
3. Drop the `.jar` file into the folder.
4. Restart or reload your server (`/reload confirm`).
